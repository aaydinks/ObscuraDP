# The two dataset files in this repository

Written in step S12 (2026-11-11) after the owner's decision that the files stay in the repository with a
note on where they come from. This note lives outside the research folders because those are frozen.

**No dataset is part of the `obscuradp` package.** `tools/check_release_contents.py` fails a release that
contains any `.csv` file or any folder named `data`, and it runs on every pull request.

## Where the files come from

What the research notes in this repository say:

| | Stroke table | Loan table |
|---|---|---|
| Named source | "fedesoriano Stroke Prediction" on Kaggle (`Experiment 1/README.md:18`, `Experiment 1/REPRODUCTION.md:12`) | Kaggle `architsharma01/loan-approval-prediction` (`Experiment 2/README.md:17`) |
| How it was fetched | "from a public GitHub mirror (Kaggle requires auth)" (`Experiment 1/REPRODUCTION.md:74`) | "mirror used because Kaggle needs auth" (`Experiment 2/README.md:138`) |
| Which mirror | **not found**: no address was recorded | **not found**: no address was recorded |
| Source page to check | `https://www.kaggle.com/datasets/fedesoriano/stroke-prediction-dataset` | `https://www.kaggle.com/datasets/architsharma01/loan-approval-prediction-dataset` |

What was checked on 2026-11-11 and what was not:

- The row counts above equal the ones the research notes give for the Kaggle tables (5,110 and 4,269). The
  loan file has the 11 feature columns those notes mention, plus an identifier and the outcome.
- The two source pages could **not** be opened from the working session (the host is outside the network
  rules of the cloud environment). The page addresses above are the usual addresses of those two Kaggle
  entries and were not confirmed by opening them.
- Because the mirror is unknown and the pages were not opened, it is **not confirmed** that the files here
  are the same, byte for byte, as the files on Kaggle.

A web search on 2026-11-11 did not show the license field of either Kaggle page, and other sites that copy
the tables give no dependable statement. Nothing is assumed here. Whoever can open the two pages while
logged in can read the license field there and replace "not found" in this note.

Until then:

- Treat both files as third-party data with unknown terms. They are kept only so that the research results
  in this repository can be reproduced.
- Do not copy them into other projects on the strength of this repository's own license (Apache-2.0). That
  license covers the code and documents, not these two files.
- The benchmark of Phase 5 downloads its further datasets from their sources with checksums (last section
  of this note). For the stroke and loan tables it still reads these copies: the source pages cannot be
  reached from the working sessions and no mirror address was recorded. The copies cannot change unnoticed
  (the fingerprint list of the frozen folders is checked on every pull request).

## Datasets of the benchmark that are not in this repository (added in S17, 2026-11-12)

The benchmark of Phase 5 uses three more datasets. None of them is stored here, and none is part of the
package.

| | Made-up health table | Handwriting (Federated EMNIST) | Text (Shakespeare) |
|---|---|---|---|
| What it is | 20,000 rows in 10 hospitals, drawn from random numbers and a hand-written rule (`obscuradp.tables.synthetic_health`) | 28 by 28 pixel images of handwritten digits and letters by 3,400 writers; 671,585 training and 77,483 test images, 62 classes | Lines of 715 speaking roles of the plays, about 2.4 million characters |
| Real people | **None.** No row describes a person | Writers of a public handwriting sample collected by NIST; no names, the writers are numbered | None (fictional roles) |
| Where it comes from | Generated by this library from a seed | `https://storage.googleapis.com/tff-datasets-public/fed_emnist.tar.bz2` | `https://storage.googleapis.com/tff-datasets-public/shakespeare.tar.bz2` |
| Size of the download | none | 169,808,360 bytes | 1,848,122 bytes |
| sha256 of the download | none | `fe1ed5a502cea3a952eb105920bff8cffb32836b5173cb18a57a32c3606f3ea0` | `0285be9906cb5f268092eee4edeeacfc2af4574f2941f7cc2f08a321d7f5c707` |
| License | Part of this library (Apache-2.0) | Packaging by the TensorFlow Federated project (Apache-2.0); the images are from NIST Special Database 19, a work of the United States government in the public domain | Packaging by the TensorFlow Federated project (Apache-2.0); the plays are in the public domain |
| Checked on 2026-11-12 | Same seed gives the same table (tested) | Size and md5 equal the values the storage service states for the file; the sha256 above was computed from that download | The same |

How they are fetched: `benchmarks/phase5/fetch.py` downloads a file once into a folder outside the
repository (`~/.cache/obscuradp-benchmarks`, or what `OBSCURADP_BENCHMARK_CACHE` names), compares its sha256
with the value above and refuses a file that differs. The library itself never opens a network connection.

What was not checked: the license statements above are those of the two projects as generally published;
their license files were not opened from the working session. The archive of the text dataset holds 715
roles, not the 1,129 that the roadmap named from another packaging of the same plays; 644 of them have
enough text for at least two reading windows and are used.
